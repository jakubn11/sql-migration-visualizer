What You Get

Nine focused capabilities, one tool window at the bottom of your IDE.

  • Timeline View

    Browse every schema version with table counts, change summaries, and quick source actions.

  • Schema Diff

    Compare any two versions to see added, removed, and modified tables and columns side-by-side.

  • ER Diagram

    Inspect relationships visually with zoom, pan, and PNG export — with a watermark for sharing.

  • Migration Validation

    Catch gaps, duplicates, invalid ALTER statements, and inconsistent history before they bite.

  • Pending Migration Suggestions

    Save your schema SQL and the plugin offers a migration draft based on the actual diff.

  • Risk Scoring

    Every migration is scored High / Medium / Low risk — dropped columns, narrowing types, and tightening nullability are surfaced automatically.

  • Create, Edit & Delete

    Manage migration files directly from the panel — including renumbering when version numbers collide.

  • Dialect-aware SQL

    Generate migrations for Generic, PostgreSQL, MySQL/MariaDB, or SQLite — the output respects each dialect's ALTER rules.

Generator dialects

The Create Migration generator respects each dialect's ALTER rules and falls back to table rebuilds when needed.

DialectNotes
Generic SQL Lowest-common-denominator output; falls back to table rebuilds for any column modification.
PostgreSQL Emits ALTER COLUMN … TYPE / SET NOT NULL / SET DEFAULT for in-place changes.
MySQL / MariaDB Emits MODIFY COLUMN / CHANGE COLUMN for in-place changes and renames.
SQLite Wraps complex column changes in the standard 12-step rebuild with PRAGMA foreign_keys guards.

Install

From source

git clone https://github.com/jakubn11/sql-migration-visualizer.git
cd sql-migration-visualizer
./gradlew buildPlugin

The built ZIP lands in build/distributions/. Install it via Settings → Plugins → ⚙ → Install Plugin from Disk.
